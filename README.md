# colfondos_prueba

Prueba técnica **Desarrollador Fullstack**: Dirección de Canales Digitales.
HU-CONTACT-001: *"Como afiliado quiero actualizar mi correo electrónico para recibir comunicaciones en mi nueva dirección."*

## Estructura del monorepo

| Carpeta     | Contenido                                                                 |
|-------------|---------------------------------------------------------------------------|
| `backend/`  | Spring Boot 3 (Java 17): orquestador de Identity/Verification, Customer Data y Messaging (simuladas) |
| `frontend/` | React + Vite: asistente paso a paso (identificación → OTP → nuevo correo → confirmación) |
| `docs/`     | Entregables E1–E7, diagramas y evidencias                                 |

## Requisitos locales

| Herramienta | Versión mínima |
|-------------|----------------|
| Java        | 17             |
| Maven       | 3.9            |
| Node        | 20             |

> La configuración local, las variables de ambiente y los comandos de arranque se completan en el paso 8 (E3).
